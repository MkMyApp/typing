GoogleFontsの使い方


フォント名タイピング

Google Fontsの導入とカスタマイズ実践ガイド

Webサイトの印象を大きく左右するフォントの選択。
標準のフォントではなく、Google Fontsを活用することで、
誰でも簡単におしゃれで読みやすいWebフォントを導入することができます。
実際に作成したテストページのソースコードをベースに、
Google Fontsの読み込みからスタイリングまでの実装方法を解説します。

GoogleFonts フォントテスト 作成ツール 

<!-- サーバーとの接続をあらかじめ準備する高速化設定 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- フォントの読み込み（1つずつ分けた書き方） スペースは + に置換 -->
<link href="https://fonts.googleapis.com/css2?family=Rubik+Spray+Paint&display=swap" rel="stylesheet">
<link href="https://fonts.googleapis.com/css2?family=Zen+Maru+Gothic&display=swap" rel="stylesheet">

<style>
.RubikSprayPaint {
    font-family: 'Rubik Spray Paint', cursive;
    font-size: 200%;
}

.ZenMaruGothic {
    font-family: 'Zen Maru Gothic', sans-serif;
    font-size: 200%;
}
</style>
