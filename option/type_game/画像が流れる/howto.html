タイピングゲームの作り方・設定マニュアル

1. 全体の仕組み・作り方の概要

このタイピングゲームは、HTML5のCanvas（背景やキャラクター・流れてくる敵・スコアの描画）と、HTMLのテキストエリア（タイピング入力・判定）を組み合わせた構成になっています。

  • game.html でゲーム全体のタイトルや出題データ、設定値を変更します。
  • game.css で画面全体のサイズやフォント、色などの見た目を調整します。
  • game.js でキャラクターや敵画像のファイル名、移動スピード、演出サイズなどを調整します。
  • typing.js はタイピングの判定や進行管理を行う本体です（通常は直接触らなくて大丈夫です）。

2. game.html での設定の調整

問題文の設定やゲームの基本動作は、game.html 内の <script> タグおよび <textarea id="txtdata"> で行います。

① ゲームの各種パラメータ設定

game.html 内の <script> 部分を変更します。

<script>
const TITLE_MSG = "ここにゲームのタイトル";  // 画面上部に表示するタイトル
const START_MSG = "Enter⏎スタート";         // スタート前のメッセージ
const INPUT_MSG = "かな 確認";              // 入力欄のプレースホルダー
const RANDOM = "10";                        // 出題数（"0"または未指定にすると全問）
const WIDTH = "20ch";                       // 入力欄の幅
const IME = "ON";                           // IMEの設定 ("ON" または "OFF")
</script>

② 問題文の登録

game.html 内の <textarea id="txtdata"> 部分に、1行につき1つ、タイピングの問題となる単語やローマ字（または日本語）を入力します。

<textarea id="txtdata" hidden>
apple
banana
orange
</textarea>

※ここに記述した文字がそのまま問題になり、後述の「対応する画像」のファイル名としても使われます。

3. 対応する画像の用意

game.js の設定により、問題文として登録した文字列と一致する画像ファイルが自動で読み込まれ、ゲーム中に敵として流れてきます。

  • 例: txtdata に apple という問題がある場合、同じフォルダ（または指定の場所）に apple.png という画像を置く必要があります。
  • 画像が見つからない場合や読み込みに失敗した場合は、フォールバック画像（img.png や bg.png など）が表示される仕組みになっています。
  • そのほか、以下の基本画像も必要に応じて用意します。
    • bg.png （背景画像）
    • you.png （プレイヤー・キャラクター画像）
    • img.png （画像が見つからないときの代わり用画像）

4. CSS (game.css) と JS (game.js) の調整部分

見た目や挙動を微調整したい場合、主に以下のファイル・プロパティを変更します。

調整したい内容 変更するファイル 主なプロパティ・場所
画面サイズや全体のデザイン game.css :root 内の --game-width, --game-height, --line-font-size など
キャラクター・敵の大きさ、速度 game.js ファイル上部の定数（YOU_HEIGHT, ENEMY_HEIGHT, BASE_SPEED 等）

A. 画面サイズや全体のデザインを変えたい場合 (game.css)

:root {
  /* ゲーム画面全体の幅・高さ */
  --game-width: 1024px;
  --game-height: 576px;

  /* フォントサイズや色の調整 */
  --line-font-size: 64px; /* タイピング文字の大きさ */
  --body-background-color: #ffffff; /* 背景色 */
}

B. キャラクターや敵の大きさ・スピード・配置を変えたい場合 (game.js)

const BGIMG ="bg.png"; // 背景画像ファイル名

const YOU_IMG= 'you.png'; // プレイヤー画像ファイル名
const YOU_HEIGHT = 300;   // プレイヤーの高さ (px)
const YOU_LEFT = 30;      // プレイヤーの左からの位置調整
const YOU_TOP = 50;       // プレイヤーの上下の位置調整

const ENEMY_HEIGHT = 300; // 敵（問題の画像）の標準の高さ
const BASE_SPEED = 1;     // 敵が左へ流れるスピード（大きくすると速くなる）

const CENTER_IMAGE_HEIGHT = 500; // タイピング正解時に中央にドンッと出る画像の大きさ
