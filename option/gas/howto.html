Googleスプレッドシートの受け側 設定手順

GitHub Pagesなどの送信側からデータを受け取り、スプレッドシートへ自動蓄積するためのGAS（Google Apps Script）設定手順です。

1

スプレッドシートの新規作成

  1. Googleドライブを開き、新しいGoogleスプレッドシートを作成します。
  2. シート名は分かりやすいもの（例: 結果集計 など）に変更します。
2

Apps Script（GAS）コードの貼り付け

  1. スプレッドシートの上部メニューにある 「拡張機能」 ＞ 「Apps Script」 の順にクリックします。
  2. 開いたエディタ画面にあるデフォルトのコードをすべて消去します。
  3. 以下のコードをコピーして貼り付けます。
function doPost(e) {
  try {
    // 1. 送信元から届いた文字列を取得
    const receivedText = e.postData ? e.postData.contents : "データなし";
    
    // 2. 現在の日時を取得
    const nowTime = new Date().toLocaleString("ja-JP");
    
    // 3. スプレッドシートの末尾に [日時, 届いた文字列] を追記
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    sheet.appendRow([nowTime, receivedText]);
    
    // 4. 送信元へ成功を返す
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

※ 貼り付けた後、画面上部のフロッピーディスクアイコン（保存ボタン）を押して保存してください。

3

Webアプリとしてのデプロイ（公開）

  1. 画面右上の 「デプロイ」 ボタン ＞ 「新しいデプロイ」 をクリックします。
  2. 左上の歯車アイコン（種類の選択）から 「ウェブアプリ」 を選択します。
  3. 各項目を以下のように設定します：
    • 説明: （任意）「結果受信」など
    • 次のユーザーとして実行: 「自分」
    • アクセスできるユーザー: 「全員」（※ここが「自分のみ」になっていると通信エラーになります）
  4. 「デプロイ」 ボタンをクリックします。
  5. 初回のみ「承認が必要です」というポップアップが出るため、「アクセスを承認」し、ご自身のGoogleアカウントを選んで進めてください。（詳細から「安全ではないページに移動」をクリックする必要がある場合があります）
  6. デプロイ完了後に表示される 「ウェブアプリのURL」 またはその中の デプロイID をコピーします。
4

送信側との紐付け

コピーしたデプロイIDを、送信側（GitHub Pages側の send.js など）の deployId 変数に貼り付ければ連携完了です！
