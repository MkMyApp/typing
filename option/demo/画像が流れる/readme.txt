タイピング1問ごとのスコア算出の仕組みについて

【スコアの計算式】
const lineScore = Math.round(cpm * (accuracy / 100));

1問（1行）をクリアした瞬間に上記の計算式が実行され、その問題でのスコアが算出されます。

・cpm (Characters Per Minute): 1分間にどれだけの文字を入力できたか（スピード）
・accuracy (%): どれだけ正確にミスなく入力できたか（正答率を100で割って小数化）
・Math.round(...): 計算結果の小数を四捨五入して整数にする

【スコア算出の設計思想】
- スピードだけでも、正確性だけでも高得点にならない
  スピード（CPM）だけが高くても、ミスが多いと正答率の割合（accuracy / 100）が下がるためスコアが伸びません。逆に、正確に打てていても極端に遅いとベースのCPMが低いため高得点になりません。
- バランス重視の評価
  「速さと正確性の両立」がそのまま高得点に直結する、非常にフェアでバランスの取れた計算式になっています。

【実際のプログラムの動き】
1問完了時に onLineComplete 関数が呼ばれ、算出されたスコア（lineScore）が直前の獲得スコアとして保持されると同時に、ゲーム全体の合計スコア（totalScore）に累積加算されていきます。
