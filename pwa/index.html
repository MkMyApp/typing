pwaの作り方
PWA（[プログレッシブウェブアプリ]とは Webサイトをスマホアプリ（ネイティブアプリ）のように使えるようにする技術のことです。 PWAの主な特徴 インストールが簡単：アプリストアを通さず、ブラウザから直接スマホのホーム画面にアイコンを追加できます。 オフラインでも動く：データを一時保存（キャッシュ）するため、電波がない場所でも閲覧できます。 表示が速い：読み込みがスムーズで、サクサク動きます。

Webアプリをフォルダに保存

右クリックから名前をつけて保存 index.html style.css typing.js

pwaに必要なファイルを保存

右クリックから名前をつけて保存 head.html manifest.json register-sw.js sw.js

register-sw.jsはそのまま

if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('./sw.js')
      .then((reg) => {
        console.log('Service Worker 登録成功:', reg.scope);
      })
      .catch((err) => {
        console.log('Service Worker 登録失敗:', err);
      });
  });
}

sw.jsを編集

const CACHE_NAME = 'typing-pwa-ver1';
const urlsToCache = [
  './',
  './index.html',
  './style.css',
  './typing.js'
];

// インストール時にファイルをキャッシュ
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then((cache) => {
        return cache.addAll(urlsToCache);
      })
  );
});

// キャッシュからレスポンスを返す
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request)
      .then((response) => {
        return response || fetch(event.request);
      })
  );
});

urlsToCacheを作成

◉すべて　◉'./pwa'　にマークして、フォルダをドロップ キャッシュする必要のあるファイルのリスト
